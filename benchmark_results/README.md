# Benchmark Results

This directory stores timestamped benchmark run outputs.
Results are generated by scripts in `scripts/` and `tests/`.

Files in this directory are excluded from version control (see `.gitignore`).

The progressive learned-memory runner writes `deep_memory_report.md` and
`deep_memory_details.json` here by default. Run it with:

```bash
venv/bin/python tests/locomo_deep_memory_sandbox.py --dry-run
```
